I joined Datastory in 2024 as a senior software engineer. My work sits on the data engineering side of the platform: collecting data from many sources, processing it, and delivering it in a form that customers can use and visualize.

## What I did

- **Healthcare ETL for a government customer.** Designed and developed a specialized ETL solution for an enterprise customer in the healthcare sector of the Swedish government, working with 1,500+ indicators and multiple API vendors.
- **Platform integration.** Integrated the new data pipelines into the Datastory cloud platform to support automated data collection and visualization, for both enterprise and non-enterprise customers.
- **Infrastructure foundation.** Laid the foundation and design of the main infrastructure repository that services the cloud platform, with integrations for 50+ open data sources and more than 4,000 indicators.
- **SDK.** Developed an SDK for the Datastory API and integrated it with the infrastructure services.
- **Orchestration.** Used data orchestration tools such as Dagster to automate the data pipelines.
- **Deployment.** Deployed the infrastructure services on AWS ECS, using the AWS Fargate serverless solution.
- **Maintenance.** Maintained and optimized the existing government healthcare software systems, including legacy data pipelines, web APIs and the frontend, fixing bugs while keeping critical data handling stable, secure and efficient.
- **AI-assisted development.** Used Claude Code for AI-assisted development, directing implementation through architectural discussion, technical planning, task decomposition and iterative problem-solving, while keeping ownership of engineering decisions and code quality.
- **Planning.** Supported the product management team with sprint planning and the product roadmap.

## Stack

- **Languages and frameworks:** Python, JavaScript, TypeScript, Java, C#, PostgreSQL, MongoDB, Dagster, .NET Core, Java EE, Node.js
- **Tools:** Claude Code, Docker, Docker Compose, AWS ECS, Bitbucket, Jira, Confluence, Notion
- **Methodologies:** Agile, Scrum, Jira-based planning, AI-assisted development
