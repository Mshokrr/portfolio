At Dell Technologies I was part of the 5G software engineering team, building the cloud-native components that 5G networks run on. The focus was on hyper-scalable, near real-time solutions.

## What I did

- **5G network components.** Designed and developed cloud-native 5G network components as part of the 5G software engineering team.
- **Architecture.** Led the architecture and implementation of microservice-based systems, improving scalability and operational efficiency.
- **APIs and backend services.** Developed APIs and backend services that improved integration and functionality.
- **Scrum Master.** Facilitated agile ceremonies and promoted best practices to improve team productivity and delivery timelines.
- **Feature Owner.** Managed the backlog for specific features and created user stories and spikes to drive development within the larger product.
- **Infrastructure.** Assisted in developing infrastructure components, keeping integration seamless and aligned with development goals.
- **Mentoring.** Mentored and guided junior engineers, fostering a culture of continuous learning and innovation within the team.

## Stack

- **Languages:** Go, Python, C++, C, Bash
- **Tools:** Docker, Podman, Buildah, Kubernetes, Helm, Redis, Red Hat Enterprise Linux
- **Methodologies:** Agile, Scrum and SAFe frameworks, Jira-based planning
