At AIM Technologies I led web development for the flagship product, AIM Insights. I owned the backend and the API, supported the frontend, and also ran the agile process and the hiring for the team.

## What I did

- **AIM Insights.** Led the design and implementation of the product, with full responsibility for the backend and API and support for the frontend development.
- **Growth.** Drove the product from 4 active users to more than 400 active users.
- **Subscriptions.** Designed and implemented a subscription model for the mass distribution of AIM Insights.
- **Testing.** Created and implemented integration and end-to-end tests.
- **Scrum Master.** Facilitated agile ceremonies in a fast-paced production environment while attending to active users' needs.
- **Hiring.** Created and implemented a hiring process and designed interviews for junior and senior developers, processing more than 80 applications and hiring 7 developers.

## Stack

- **Languages:** JavaScript, Python, Java
- **Frameworks:** Node.js, Express.js, NestJS, FastAPI, Java Spring, React/Redux
- **Tools:** Docker, Kubernetes, Google Cloud Platform, Microsoft Azure, AWS
- **Methodologies:** Agile and Scrum, Jira-based planning
